Un seul binaire. Tout est inclus.

Chaque build est un unique exécutable autonome : la réparation (par2) et l’extraction (RAR) sont embarquées. Dézippez, lancez le lanceur, répondez à trois questions, téléchargez.

🍎 macOS disponible

L’app NzbFast : glissez-la dans Applications et c’est parti. Universelle (Apple Silicon et Intel), tableau de bord dans sa propre fenêtre, double-clic sur les .nzb, lancement à l’ouverture de session.

macOS 12+ · DMG de ~16 MB · app + moteur

Pas encore notariée par Apple : le premier lancement demande deux clics de plus ; le DMG vous accompagne, et un guide complet se trouve directement sur le disque.

Télécharger l’app Mac .zip portable

🪟 Windows disponible

L’installeur met en place une app de barre d’état (sans fenêtre de console), une entrée dans le menu Démarrer, le démarrage avec Windows en option et le double-clic sur les .nzb. Entièrement statique, aucun runtime à installer ; il peut aussi adopter votre config SABnzbd existante.

Windows 10/11 x64 · installeur de ~8 MB

Télécharger l’installeur .zip portable

🐧 Linux disponible

Builds statiques musl pour x86_64 et arm64 : seedboxes, VPS, tout NAS avec SSH, Raspberry Pi 4/5. Fini la roulette des versions de glibc.

x86_64 · arm64 · unité systemd incluse

x86_64 arm64

🐳 Docker disponible

Image multi-arch (amd64 + arm64) sur Docker Hub et ghcr, point d'entrée PUID/PGID façon linuxserver, healthcheck, fichier compose. C'est aussi la voie pour Unraid, TrueNAS SCALE et QNAP Container Station.

docker run -d -p 6789:6789 -e NZBFAST_OUT=/data/usenet \
  -v /srv/nzbfast/config:/config -v /srv/nzbfast/watch:/watch \
  -v /data/usenet:/data/usenet nzbfast/nzbfast

🍺 Homebrew disponible

Une seule commande sur macOS et Linux, avec un bloc service pour qu’il démarre à l’ouverture de session (brew services start nzbfast). Les mises à jour se font avec brew upgrade nzbfast, et vos paramètres comme votre file d’attente vivent en dehors de l’installation : ils y survivent.

macOS (Apple Silicon + Intel) · Linux x86_64 + arm64

brew install nzbfast/tap/nzbfast

Ces boutons pointent vers la version actuelle. Si un lien ne fonctionne plus, ou si vous voulez une version antérieure, les sommes de contrôle ou les notes de version, tout se trouve sur la page des versions GitHub.

Vérifier les téléchargements : chaque version publie des sommes sha256 à côté des artefacts sur la page des releases. Les zips macOS conservent les bits d’exécution ; les builds ne sont pas encore signés, macOS demande donc confirmation au premier lancement : clic droit sur l’app, puis Ouvrir (macOS 14 et antérieurs), ou autorisez-la dans Réglages Système → Confidentialité et sécurité → Ouvrir quand même (macOS 15 et ultérieurs).

Deux minutes jusqu’au premier téléchargement

  • 1. Dézippez et lancez Start nzbfast (mac : .command, windows : .bat), ou simplement ./nzbfast setup dans un terminal.
  • 2. L’assistant repère une config SABnzbd/NZBGet existante et propose de l’utiliser ; sinon, il vous demande l’hôte, le nom d’utilisateur, le mot de passe et le nombre de connexions de votre fournisseur.
  • 3. Le tableau de bord s’ouvre sur http://localhost:6789. Déposez-y un .nzb n’importe où, ou pointez Sonarr/Radarr dessus comme client SABnzbd.

Mettre à jour, c’est remplacer un seul fichier. Les paramètres, la file d’attente et l’historique vivent à côté de votre config et survivent aux redémarrages comme aux mises à jour.

Notes par plateforme

  • Raspberry Pi / NAS ARM : utilisez le build Linux arm64. Le décodage SIMD du moteur dispose de noyaux NEON ; un Pi 5 sature le gigabit avec de la marge.
  • Unraid : dans Community Apps : cherchez nzbfast dans l’onglet Apps et installez (image Docker en dessous). Guide pas à pas →
  • TrueNAS SCALE : lancez l’image Docker en tant qu’app personnalisée.
  • FreeBSD / autres : cargo build --release depuis les sources devrait fonctionner (rustls, pas d’OpenSSL) ; non testé officiellement. La réparation PAR2 et l’extraction RAR sont natives sur toutes les plateformes.
  • Téléphones : rien à installer : le tableau de bord offre une vraie disposition téléphone, et nzb360/LunaSea se connectent via l’API compatible SABnzbd.
