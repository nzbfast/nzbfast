Én binær. Alt inkludert.

Hver bygg er én enkelt selvstendig kjørbar fil: reparasjon (par2) og utpakking (RAR) er innebygd. Pakk ut, kjør launcheren, svar på tre spørsmål, last ned.

🍎 macOS tilgjengelig

NzbFast-appen: dra til Programmer og kjør i gang. Universal (Apple Silicon og Intel), dashbord i sitt eget vindu, .nzb-dobbeltklikk, Start ved pålogging.

macOS 12+ · ~16 MB DMG · app + motor

Ennå ikke notarisert av Apple, så første oppstart krever to ekstra klikk; DMG-en leder deg gjennom, og en komplett veiledning ligger på selve disken.

Last ned Mac-appen portabel .zip

🪟 Windows tilgjengelig

Installasjonsprogrammet setter opp en statusfelt-app (uten konsollvindu), Start-meny-oppføring, valgfri start-med-Windows og .nzb-dobbeltklikk. Helt statisk, ingen runtime å installere; den kan også overta det eksisterende SABnzbd-oppsettet ditt.

Windows 10/11 x64 · ~8 MB installasjonsprogram

🐧 Linux tilgjengelig

Statiske musl-bygg for x86_64 og arm64: seedbokser, VPS-er, hvilken som helst NAS med SSH, Raspberry Pi 4/5. Ingen glibc-versjonsrulett.

x86_64 · arm64 · systemd-enhet inkludert

x86_64 arm64

🐳 Docker tilgjengelig

Multi-arch-image (amd64 + arm64) på Docker Hub og ghcr, PUID/PGID-entrypoint i linuxserver-stil, healthcheck, compose-fil. Også veien for Unraid, TrueNAS SCALE og QNAP Container Station.

docker run -d -p 6789:6789 \
  -v ./config:/config -v ./downloads:/downloads -v ./watch:/watch \
  nzbfast/nzbfast

🍺 Homebrew tilgjengelig

Én kommando på macOS og Linux, med en tjenesteblokk så den starter ved pålogging (brew services start nzbfast). Oppgradering er brew upgrade nzbfast, og innstillingene og køen din ligger utenfor installasjonen, så de overlever den.

macOS (Apple Silicon + Intel) · Linux x86_64 + arm64

brew install nzbfast/tap/nzbfast

Knappene peker på den gjeldende versjonen. Hvis en lenke slutter å virke, eller du vil ha en eldre versjon, sjekksummene eller versjonsnotatene, finnes alt på GitHubs releaseside.

Verifisere nedlastinger: hver utgave leveres med sha256-summer ved siden av artefaktene på utgivelsessiden. macOS-zip-er bevarer kjørbare biter; utgivelsene er ennå ikke signert, så macOS spør før første oppstart: høyreklikk på appen og velg Åpne (macOS 14 og eldre), eller tillat den under Systeminnstillinger → Personvern og sikkerhet → Åpne likevel (macOS 15 og nyere).

To minutter til første nedlasting

  • 1. Pakk ut og kjør Start nzbfast (mac: .command, windows: .bat), eller bare ./nzbfast setup i en terminal.
  • 2. Veiviseren finner et eksisterende SABnzbd-/NZBGet-oppsett og tilbyr å bruke det; ellers spør den om leverandørens host, brukernavn, passord og antall tilkoblinger.
  • 3. Dashbordet åpner på http://localhost:6789. Slipp en .nzb hvor som helst på det, eller pek Sonarr/Radarr mot det som en SABnzbd-klient.

Å oppgradere er å bytte ut én fil. Innstillinger, kø og historikk ligger ved siden av config-en din og overlever omstarter og oppgraderinger.

Plattformmerknader

  • Raspberry Pi / ARM NAS: bruk Linux arm64-bygget. Motorens SIMD-dekoding har NEON-kjerner; en Pi 5 metter gigabit med margin.
  • Unraid: i Community Apps: søk etter nzbfast i Apps-fanen og installer (Docker-image under). Trinnvis veiledning →
  • TrueNAS SCALE: kjør Docker-imaget som en egendefinert app.
  • FreeBSD / andre: cargo build --release fra kildekode forventes å fungere (rustls, ingen OpenSSL); offisielt utestet. PAR2-reparasjon og RAR-utpakking er native på alle plattformer.
  • Telefoner: ingenting å installere: dashbordet har en førsteklasses telefonlayout, og nzb360/LunaSea kobler til via det NZBGet-kompatible API-et.
