Un solo binario. Tutto incluso.

Ogni build è un unico eseguibile autonomo: riparazione (par2) ed estrazione (RAR) sono incorporate. Estrai, avvia il launcher, rispondi a tre domande, scarica.

🍎 macOS disponibile

L'app NzbFast: trascinala in Applicazioni e via. Universale (Apple Silicon e Intel), dashboard in una finestra propria, doppio clic sui .nzb, avvio all'accesso.

macOS 12+ · DMG ~16 MB · app + motore

Non ancora notarizzata da Apple, quindi il primo avvio richiede due clic in più; il DMG ti accompagna, con una guida completa direttamente sul disco.

🪟 Windows disponibile

L'installer configura un'app nella tray (nessuna finestra di console), una voce nel menu Start, l'avvio con Windows opzionale e il doppio clic sui .nzb. Completamente statico, nessun runtime da installare; può anche adottare la tua configurazione SABnzbd esistente.

🐳 Docker disponibile

Immagine multi-arch (amd64 + arm64) su Docker Hub e ghcr, entrypoint PUID/PGID in stile linuxserver, healthcheck, file compose. È anche la via per Unraid, TrueNAS SCALE e QNAP Container Station.

docker run -d -p 6789:6789 -e NZBFAST_OUT=/data/usenet \
  -v /srv/nzbfast/config:/config -v /srv/nzbfast/watch:/watch \
  -v /data/usenet:/data/usenet nzbfast/nzbfast

🍺 Homebrew disponibile

Un solo comando su macOS e Linux, con un blocco service perché parta all’accesso (brew services start nzbfast). Per aggiornare basta brew upgrade nzbfast, e le tue impostazioni e la coda risiedono fuori dall’installazione, quindi sopravvivono all’aggiornamento.

macOS (Apple Silicon + Intel) · Linux x86_64 + arm64

brew install nzbfast/tap/nzbfast

Questi pulsanti puntano alla versione corrente. Se un collegamento non funziona, o se vuoi una versione precedente, i checksum o le note di rilascio, trovi tutto nella pagina delle release su GitHub.

Verificare i download: ogni release pubblica le somme sha256 accanto agli artefatti nella pagina delle release. Gli zip macOS preservano i bit di esecuzione; le build non sono ancora firmate, quindi macOS chiede conferma al primo avvio: clic destro sull’app e scegli Apri (macOS 14 e precedenti), oppure autorizzala in Impostazioni di Sistema → Privacy e sicurezza → Apri comunque (macOS 15 e successivi).

Due minuti al primo download

  • 1. Estrai ed esegui Start nzbfast (mac: .command, windows: .bat), oppure semplicemente ./nzbfast setup in un terminale.
  • 2. La procedura guidata trova una configurazione SABnzbd/NZBGet esistente e propone di usarla; altrimenti chiede host, nome utente, password e numero di connessioni del tuo provider.
  • 3. La dashboard si apre su http://localhost:6789. Trascinaci sopra un .nzb ovunque, oppure puntaci Sonarr/Radarr come client SABnzbd.

Aggiornare significa sostituire un file. Impostazioni, coda e storico risiedono accanto alla tua configurazione e sopravvivono a riavvii e aggiornamenti.

Note per piattaforma

  • Raspberry Pi / NAS ARM: usa la build Linux arm64. La decodifica SIMD del motore ha kernel NEON; un Pi 5 satura il gigabit con margine.
  • Unraid: in Community Apps: cerca nzbfast nella scheda Apps e installa (immagine Docker sotto). Guida passo passo →
  • TrueNAS SCALE: esegui l'immagine Docker come app personalizzata.
  • FreeBSD / altri: cargo build --release dai sorgenti dovrebbe funzionare (rustls, niente OpenSSL); ufficialmente non testato. La riparazione PAR2 e l'estrazione RAR sono native su tutte le piattaforme.
  • Telefoni: niente da installare: la dashboard ha un layout per telefono di prima classe, e nzb360/LunaSea si connettono tramite l'API compatibile SABnzbd.
