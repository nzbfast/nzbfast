How to install NzbFast

Two minutes, including the one extra step macOS adds for apps that are not yet Apple-notarized.

1. Install

  1. Upgrading? Quit NzbFast first if it is running (right-click its Dock icon, Quit). A copy installed over a running app can leave the old version running underneath the new files.
  2. Drag NzbFast onto the Applications folder in this window.
  3. Eject the disk: click the eject icon next to nzbfast in the Finder sidebar (or drag it to the Trash).

2. First launch

NzbFast is not yet signed with an Apple Developer ID, so macOS will not open it with a plain double-click the first time. What you see depends on your macOS version; both paths are one-time only, and every later launch is a normal double-click.

These dialogs call the app nzbfast, in lower case, while the Finder shows it as NzbFast. Both are this app: macOS quotes the name the app displays, and the Finder shows its file name. On UK English the Move to Trash button below reads Move to Bin.

macOS 12 to 14 (Monterey, Ventura, Sonoma)

  1. Open your Applications folder.
  2. Right-click (or Control-click) NzbFast and choose Open.
  3. A dialog warns that the app is from an unidentified developer or cannot be verified. Because you used right-click Open, it has an Open button; click it.
"nzbfast" can't be opened because Apple cannot check it for malicious software.
OpenCancel

macOS 15 and newer (Sequoia, Tahoe and later)

On these versions the right-click trick no longer offers an Open button, so the first attempt is always blocked. That is expected; the unblock lives in System Settings.

  1. Double-click NzbFast in Applications. macOS shows:
"nzbfast" Not Opened - Apple could not verify "nzbfast" is free of malware that may harm your Mac or compromise your privacy.
DoneMove to Trash
  1. Click Done (not Move to Trash).
  2. Open System Settings > Privacy & Security and scroll down to the Security section.
  3. You will see "nzbfast" was blocked to protect your Mac. Click Open Anyway.
  4. Confirm in the dialog that follows (click Open Anyway again, then Open); macOS may ask for your password or Touch ID.

Why all this? macOS Gatekeeper flags any app that is not notarized through a paid Apple Developer account. NzbFast's code is open and its release checksums are published; proper signing and notarization are planned for a future release, which removes these steps entirely.

3. If something goes wrong

The icon bounces in the Dock and the app never opens

The quarantine flag can wedge an unsigned app. Clear it: open Terminal (in Applications > Utilities), paste this line, and press Return, then launch NzbFast again.

xattr -dr com.apple.quarantine /Applications/NzbFast.app
"nzbfast" is damaged and can't be opened

Same cause, same fix: run the xattr command above. If it still will not open, delete the app and reinstall from a freshly downloaded DMG.

Still frozen, and you are on a macOS beta

Beta builds of macOS can wedge the system's first-launch app assessment service, which freezes every new app before its first instruction runs; the xattr command does not help there. Reboot the Mac and launch again; this has been diagnosed and cleared by a reboot on a macOS beta.

4. After that

NzbFast opens its dashboard in a window, asks for your Usenet provider's details on first run (or offers to reuse an existing SABnzbd or NZBGet config), and can start at login from its menu. The full manual is one click away: the manual button in the dashboard header. An offline copy also ships on this disk (press Cmd-Shift-. in the DMG window to reveal hidden files, then open .extras/MANUAL.html).
