Varje bygge är en enda fristående körbar fil: reparation (par2) och uppackning (RAR) är inbäddade. Packa upp, kör startaren, svara på tre frågor, ladda ner.

🍎 macOS tillgänglig

NzbFast-appen: dra till Program och kör. Universell (Apple Silicon och Intel), instrumentpanel i sitt eget fönster, .nzb-dubbelklick, Starta vid inloggning.

macOS 12+ · ~16 MB DMG · app + motor

Ännu inte notariserad av Apple, så första starten kräver två extra klick; DMG:n guidar dig, och en fullständig guide ligger på själva skivan.

🪟 Windows tillgänglig

Installeraren sätter upp en fältapp (inget konsolfönster), Startmeny-post, valfri starta-med-Windows och .nzb-dubbelklick. Helt statisk, ingen runtime att installera; den kan även adoptera din befintliga SABnzbd-konfig.

Windows 10/11 x64 · ~8 MB installer

🐧 Linux tillgänglig

Statiska musl-byggen för x86_64 och arm64: seedboxar, VPS:er, valfri NAS med SSH, Raspberry Pi 4/5. Ingen glibc-versionsrysk roulett.

x86_64 · arm64 · systemd-enhet inkluderad

🐳 Docker tillgänglig

Multi-arch-avbildning (amd64 + arm64) på Docker Hub och ghcr, PUID/PGID-entrypoint i linuxserver-stil, healthcheck, compose-fil. Även vägen för Unraid, TrueNAS SCALE och QNAP Container Station.

docker run -d -p 6789:6789 -e NZBFAST_OUT=/data/usenet \
  -v /srv/nzbfast/config:/config -v /srv/nzbfast/watch:/watch \
  -v /data/usenet:/data/usenet nzbfast/nzbfast

🍺 Homebrew tillgänglig

Ett kommando på macOS och Linux, med ett service-block så att den startar vid inloggning (brew services start nzbfast). Uppgradering är brew upgrade nzbfast, och dina inställningar och din kö ligger utanför installationen, så de överlever den.

macOS (Apple Silicon + Intel) · Linux x86_64 + arm64

brew install nzbfast/tap/nzbfast

Knapparna pekar på den aktuella versionen. Om en länk slutar fungera, eller om du vill ha en äldre version, kontrollsummorna eller versionsinformationen, finns allt på GitHubs releasesida.

Verifiera nedladdningar: varje utgåva levererar sha256-summor bredvid artefakterna på utgåvesidan. macOS-zip:ar bevarar körbarhetsbitar; utgåvorna är ännu inte signerade, så macOS frågar före första starten: högerklicka på appen och välj Öppna (macOS 14 och tidigare), eller tillåt den under Systeminställningar → Integritet & säkerhet → Öppna ändå (macOS 15 och senare).

Två minuter till första nedladdningen

  • 1. Packa upp och kör Start nzbfast (mac: .command, windows: .bat), eller bara ./nzbfast setup i en terminal.
  • 2. Guiden hittar en befintlig SABnzbd-/NZBGet-konfig och erbjuder att använda den; annars frågar den efter din providers host, användarnamn, lösenord och anslutningsantal.
  • 3. Instrumentpanelen öppnas på http://localhost:6789. Släpp en .nzb var som helst på den, eller rikta Sonarr/Radarr mot den som en SABnzbd-klient.

Att uppgradera är att byta ut en fil. Inställningar, kö och historik ligger bredvid din konfig och överlever omstarter och uppgraderingar.

Plattformsnoter

  • Raspberry Pi / ARM NAS: använd Linux arm64-bygget. Motorns SIMD-avkodning har NEON-kärnor; en Pi 5 mättar gigabit med marginal.
  • Unraid: i Community Apps: sök efter nzbfast i Apps-fliken och installera (Docker-image under huven). Steg-för-steg-guide →
  • TrueNAS SCALE: kör Docker-imagen som en custom app.
  • FreeBSD / övrigt: cargo build --release från källkod förväntas fungera (rustls, ingen OpenSSL); officiellt otestat. PAR2-reparation och RAR-uppackning är native på alla plattformar.
  • Telefoner: inget att installera: instrumentpanelen har en förstklassig telefonlayout, och nzb360/LunaSea ansluter via det SABnzbd-kompatibla API:et.
