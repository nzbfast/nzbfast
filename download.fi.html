Yksi binääri. Kaikki mukana.

Jokainen koonti on yksi itsenäinen suoritettava tiedosto: korjaus (par2) ja purku (RAR) ovat upotettuina. Pura, aja käynnistin, vastaa kolmeen kysymykseen, lataa.

🍎 macOS saatavilla

NzbFast-sovellus: vedä Ohjelmiin ja mene. Universaali (Apple Silicon ja Intel), koontinäyttö omassa ikkunassaan, .nzb-kaksoisnapsautus, käynnistys kirjautumisessa.

macOS 12+ · ~16 MB DMG · sovellus + moottori

Ei vielä Applen notarisoima, joten ensimmäinen käynnistys vaatii kaksi lisänapsautusta; DMG opastaa niiden läpi, ja täydellinen opas on itse levyllä.

🪟 Windows saatavilla

Asennusohjelma pystyttää ilmaisinaluesovelluksen (ei konsoli-ikkunaa), Käynnistä-valikon merkinnän, valinnaisen Windowsin-kanssa-käynnistyksen ja .nzb-kaksoisnapsautuksen. Täysin staattinen, ei asennettavaa ajoympäristöä; se voi myös omaksua olemassa olevan SABnzbd-määrityksesi.

Windows 10/11 x64 · ~8 MB asennusohjelma

🐧 Linux saatavilla

Staattiset musl-koonnit x86_64:lle ja arm64:lle: seedboxit, VPS:t, mikä tahansa NAS SSH:lla, Raspberry Pi 4/5. Ei glibc-versioruletttia.

x86_64 · arm64 · systemd-yksikkö mukana

x86_64 arm64

🐳 Docker saatavilla

Multi-arch-levykuva (amd64 + arm64) Docker Hubissa ja ghcr:ssä, linuxserver-tyylinen PUID/PGID-entrypoint, healthcheck, compose-tiedosto. Myös reitti kohteille Unraid, TrueNAS SCALE ja QNAP Container Station.

docker run -d -p 6789:6789 \
  -v ./config:/config -v ./downloads:/downloads -v ./watch:/watch \
  nzbfast/nzbfast

🧡 Unraid saatavilla

Kohdassa Community Applications: hae nzbfast Apps-välilehdeltä ja napsauta Install. Malli täyttää portin 6789, kolme polkua ja Unraidin käyttäjätunnukset, joten mitään ei tarvitse kirjoittaa käsin.

🍺 Homebrew saatavilla

Yksi komento macOS:llä ja Linuxilla, mukana palvelulohko, joka käynnistää sen kirjautumisessa (brew services start nzbfast). Päivitys on brew upgrade nzbfast, ja asetuksesi ja jonosi asuvat asennuksen ulkopuolella, joten ne selviävät siitä.

macOS (Apple Silicon + Intel) · Linux x86_64 + arm64

brew install nzbfast/tap/nzbfast

Painikkeet osoittavat nykyiseen julkaisuun. Jos linkki lakkaa toimimasta tai haluat vanhemman version, tarkistussummat tai julkaisutiedot, ne kaikki löytyvät GitHubin julkaisusivulta.

Latausten varmistaminen: jokainen julkaisu toimittaa sha256-summat artefaktien vieressä julkaisusivulla. macOS-zipit säilyttävät suoritusbitit; julkaisuja ei ole vielä allekirjoitettu, joten macOS kysyy ennen ensimmäistä käynnistystä: napsauta sovellusta hiiren kakkospainikkeella ja valitse Avaa (macOS 14 ja vanhemmat), tai salli se kohdassa Järjestelmäasetukset → Tietosuoja & turvallisuus → Avaa silti (macOS 15 ja uudemmat).

Kaksi minuuttia ensimmäiseen lataukseen

  • 1. Pura ja aja Start nzbfast (mac: .command, windows: .bat), tai vain ./nzbfast setup terminaalissa.
  • 2. Velho löytää olemassa olevan SABnzbd/NZBGet-määrityksen ja tarjoutuu käyttämään sitä; muuten se kysyy palveluntarjoajasi osoitteen, käyttäjänimen, salasanan ja yhteysmäärän.
  • 3. Koontinäyttö avautuu osoitteessa http://localhost:6789. Pudota .nzb minne tahansa sillä, tai osoita Sonarr/Radarr siihen SABnzbd-asiakkaana.

Päivittäminen on yhden tiedoston korvaamista. Asetukset, jono ja historia asuvat määrityksesi vieressä ja selviävät uudelleenkäynnistyksistä ja päivityksistä.

Alustahuomiot

  • Raspberry Pi / ARM NAS: käytä Linuxin arm64-koontia. Moottorin SIMD-dekoodauksella on NEON-ytimet; Pi 5 kyllästää gigabitin pelivaralla.
  • Unraid: Community Apps -sovelluksista: hae nzbfast Apps-välilehdeltä ja asenna (Docker-kuva alla). Vaiheittainen opas →
  • TrueNAS SCALE: aja Docker-kuva mukautettuna sovelluksena.
  • FreeBSD / muut: cargo build --release lähdekoodista odotetaan toimivan (rustls, ei OpenSSL:ää); virallisesti testaamaton. PAR2-korjaus ja RAR-purku ovat natiiveja kaikilla alustoilla.
  • Puhelimet: ei mitään asennettavaa: koontinäytöllä on ensiluokkainen puhelinasettelu, ja nzb360/LunaSea yhdistyvät NZBGet-yhteensopivan API:n kautta.
