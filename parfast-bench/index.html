parfast benchmark logs

Every log behind the parfast benchmark page, the JSON the page is built from, and the harnesses that produced all of it. Each figure on that page is a median of timings written to one of these files, so any of them can be traced back to the line it came from.

Machines are named by their silicon rather than by a hostname: intel-i5-10600kf, intel-core-ultra-9-386h, amd-ryzen-9800x3d, apple-m5-max, apple-m3-ultra, apple-m1-ultra-64gb and apple-m1-ultra-128gb. The BOX line at the head of each round carries the core count, the memory and the operating system, which is what a figure has to be read against. Working directories read <rig>: which drive a round ran on says nothing about the measurement. The same rule applies to the file names on this page, so a log a round wrote under the name of the machine it ran on is published under the part instead.
