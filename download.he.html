בינארי אחד. הכול כלול.

כל בנייה היא קובץ הפעלה עצמאי יחיד: תיקון (par2) ו פריקה (RAR) משובצים. חלץ, הרץ את המשגר, ענה על שלוש שאלות, הורד.

🍎 macOS זמין

אפליקציית NzbFast: גרור ל-Applications וקדימה. אוניברסלי (Apple Silicon ו- Intel), לוח מחוונים בחלון משלו, לחיצה כפולה על ‎.nzb, הפעלה בכניסה.

macOS 12+ · ~16 MB DMG · אפליקציה + מנוע

עדיין לא מאושרת-נוטריון של Apple, ולכן ההפעלה הראשונה דורשת שתי לחיצות נוספות; ה-DMG מלווה אתכם, ומדריך מלא נמצא על הדיסק עצמו.

הורד את אפליקציית ה-Mac ‎.zip נייד

🪟 Windows זמין

המתקין מגדיר אפליקציית מגש (בלי חלון קונסולה), רשומת תפריט התחל, הפעלה-עם-Windows אופציונלית ולחיצה כפולה על ‎.nzb. סטטי מלא, בלי סביבת ריצה להתקין; הוא גם יכול לאמץ את תצורת ה-SABnzbd הקיימת שלך.

Windows 10/11 x64 · מתקין ~8 MB

🐧 Linux זמין

בניות musl סטטיות ל-x86_64 ו-arm64: seedboxes, שרתי VPS, כל NAS עם SSH, Raspberry Pi 4/5. בלי רולטת גרסאות glibc.

x86_64 · arm64 · יחידת systemd כלולה

x86_64 arm64

🐳 Docker זמין

תמונת multi-arch‏ (amd64 + arm64) ב-Docker Hub וב-ghcr, נקודת כניסה PUID/PGID בסגנון linuxserver, healthcheck, קובץ compose. זו גם הדרך עבור Unraid, TrueNAS SCALE ו-QNAP Container Station.

docker run -d -p 6789:6789 -e NZBFAST_OUT=/data/usenet \
  -v /srv/nzbfast/config:/config -v /srv/nzbfast/watch:/watch \
  -v /data/usenet:/data/usenet nzbfast/nzbfast

🍺 Homebrew זמין

פקודה אחת ב-macOS וב-Linux, עם בלוק שירות כדי שיופעל בכניסה (brew services start nzbfast). שדרוג הוא brew upgrade nzbfast, וההגדרות והתור שלך נמצאים מחוץ להתקנה, ולכן הם שורדים אותו.

macOS (Apple Silicon + Intel) · Linux x86_64 + arm64

brew install nzbfast/tap/nzbfast

הכפתורים מפנים לגרסה הנוכחית. אם קישור מפסיק לעבוד, או שדרושה לכם גרסה ישנה יותר, סכומי הביקורת או הערות הגרסה, הכול נמצא בעמוד השחרורים ב-GitHub.

אימות הורדות: כל מהדורה נשלחת עם סכומי sha256 ליד הפריטים בעמוד המהדורות. קובצי zip של macOS משמרים ביטי הפעלה; הגרסאות עדיין אינן חתומות, ולכן macOS שואל לפני ההפעלה הראשונה: לחצו לחיצה ימנית על האפליקציה ובחרו ״פתח״ (macOS 14 ומטה), או אשרו אותה דרך System Settings → Privacy & Security → Open Anyway (macOS 15 ומעלה).

שתי דקות להורדה הראשונה

  • 1. חלץ והרץ Start nzbfast (mac: ‎.command, windows: ‎.bat), או פשוט ./nzbfast setup בטרמינל.
  • 2. האשף מוצא תצורת SABnzbd/NZBGet קיימת ומציע להשתמש בה; אחרת הוא מבקש את המארח, שם המשתמש, הסיסמה ומספר החיבורים של הספק שלך.
  • 3. לוח המחוונים נפתח ב-http://localhost:6789. הנח עליו ‎.nzb בכל מקום, או כוון אליו את Sonarr/Radarr כקליינט SABnzbd.

שדרוג הוא החלפה של קובץ אחד. הגדרות, תור ו היסטוריה חיים ליד התצורה שלך ושורדים הפעלות מחדש ושדרוגים.

הערות פלטפורמה

  • Raspberry Pi / ARM NAS: השתמש בבניית Linux arm64. פענוח ה-SIMD של המנוע כולל ליבות NEON; Pi 5 מרווה גיגה-ביט עם מרווח.
  • Unraid: ב-Community Apps: חפשו nzbfast בלשונית Apps והתקינו (תמונת Docker מתחת). מדריך שלב אחר שלב →
  • TrueNAS SCALE: הרץ את תמונת ה-Docker כאפליקציה מותאמת אישית.
  • FreeBSD / אחרים: cargo build --release מהמקור צפוי לעבוד (rustls, ללא OpenSSL); לא נבדק רשמית. תיקון PAR2 ופריקת RAR הם מקוריים בכל פלטפורמה.
  • טלפונים: אין מה להתקין: ללוח המחוונים יש פריסת טלפון מהמעלה הראשונה, ו-nzb360/LunaSea מתחברים דרך ה-API התואם-SABnzbd.
