Um binário. Tudo incluído.

Cada build é um único executável autossuficiente: reparo (par2) e extração (RAR) estão embutidos. Descompacte, execute o lançador, responda três perguntas, baixe.

🍎 macOS disponível

O app NzbFast: arraste para Aplicativos e pronto. Universal (Apple Silicon e Intel), painel em sua própria janela, duplo clique em .nzb, iniciar ao fazer login.

macOS 12+ · ~16 MB DMG · app + motor

Ainda não autenticada pela Apple, por isso a primeira abertura pede dois cliques extra; o DMG mostra o caminho, e há um guia completo no próprio disco.

🪟 Windows disponível

O instalador configura um app de bandeja (sem janela de console), entrada no Menu Iniciar, opção de iniciar com o Windows e duplo clique em .nzb. Totalmente estático, sem runtime para instalar; também pode adotar sua configuração existente do SABnzbd.

🐧 Linux disponível

Builds musl estáticos para x86_64 e arm64: seedboxes, VPSes, qualquer NAS com SSH, Raspberry Pi 4/5. Sem roleta de versão do glibc.

x86_64 · arm64 · unidade systemd incluída

🐳 Docker disponível

Imagem multi-arch (amd64 + arm64) no Docker Hub e no ghcr, entrypoint PUID/PGID ao estilo linuxserver, healthcheck, ficheiro compose. É também o caminho para Unraid, TrueNAS SCALE e QNAP Container Station.

docker run -d -p 6789:6789 -e NZBFAST_OUT=/data/usenet \
  -v /srv/nzbfast/config:/config -v /srv/nzbfast/watch:/watch \
  -v /data/usenet:/data/usenet nzbfast/nzbfast

🍺 Homebrew disponível

Um comando no macOS e no Linux, com um bloco de serviço para iniciar ao fazer login (brew services start nzbfast). Para atualizar, use brew upgrade nzbfast, e seus ajustes e sua fila ficam fora da instalação, então sobrevivem a ela.

macOS (Apple Silicon + Intel) · Linux x86_64 + arm64

brew install nzbfast/tap/nzbfast

Estes botões apontam para a versão atual. Se algum link falhar, ou se quiser uma versão anterior, as somas de verificação ou as notas de lançamento, está tudo na página de versões do GitHub.

Verificando os downloads: cada versão traz somas sha256 ao lado dos artefatos na página de versões. Os zips do macOS preservam os bits de execução; as builds ainda não são assinadas, então o macOS pergunta antes da primeira abertura: clique com o botão direito no app e escolha Abrir (macOS 14 e anteriores), ou permita-o em Ajustes do Sistema → Privacidade & Segurança → Abrir Assim Mesmo (macOS 15 e posteriores).

Dois minutos até o primeiro download

  • 1. Descompacte e execute Start nzbfast (mac: .command, windows: .bat), ou apenas ./nzbfast setup em um terminal.
  • 2. O assistente encontra uma configuração existente do SABnzbd/NZBGet e se oferece para usá-la; caso contrário, pede o host, o usuário, a senha e a contagem de conexões do seu provedor.
  • 3. O painel abre em http://localhost:6789. Solte um .nzb em qualquer lugar dele, ou aponte o Sonarr/Radarr para ele como cliente SABnzbd.

Atualizar é substituir um arquivo. Ajustes, fila e histórico ficam ao lado da sua configuração e sobrevivem a reinícios e atualizações.

Notas por plataforma

  • Raspberry Pi / NAS ARM: use o build Linux arm64. A decodificação SIMD do motor tem kernels NEON; um Pi 5 satura gigabit com folga.
  • Unraid: no Community Apps: procure nzbfast na aba Apps e instale (imagem Docker por baixo). Guia passo a passo →
  • TrueNAS SCALE: rode a imagem Docker como um app personalizado.
  • FreeBSD / outros: espera-se que cargo build --release a partir do código funcione (rustls, sem OpenSSL); oficialmente sem testes. O reparo PAR2 e a extração RAR são nativos em todas as plataformas.
  • Celulares: nada para instalar: o painel tem um layout de celular de primeira classe, e o nzb360/LunaSea conectam pela API compatível com o SABnzbd.
