یک باینری. همه‌چیز همراه.

هر بیلد یک فایل اجرایی خودکفای واحد است: تعمیر (par2) و باز کردن (RAR) تعبیه‌شده‌اند. اکسترکت کنید، راه‌انداز را اجرا کنید، به سه سؤال پاسخ دهید، دانلود کنید.

🍎 macOS در دسترس

اپ NzbFast: به Applications بکشید و شروع کنید. یونیورسال (Apple Silicon و Intel)، داشبورد در پنجرهٔ خودش، دوکلیک ‎.nzb، شروع هنگام ورود.

macOS 12+ · ~16 MB DMG · اپ + موتور

هنوز توسط Apple تأیید محضری نشده است، بنابراین اولین اجرا دو کلیک اضافی می‌خواهد؛ فایل DMG شما را راهنمایی می‌کند و راهنمای کامل روی خود دیسک است.

دانلود اپ مک ‎.zip قابل حمل

🪟 Windows در دسترس

نصاب یک اپ سینی (بدون پنجرهٔ کنسول)، ورودی منوی Start، شروع-با-Windows اختیاری و دوکلیک ‎.nzb راه‌اندازی می‌کند. کاملاً ایستا، بدون زمان‌اجرا برای نصب؛ می‌تواند پیکربندی موجود SABnzbd شما را هم بپذیرد.

Windows 10/11 x64 · ~8 MB نصاب

دانلود نصاب ‎.zip قابل حمل

🐧 Linux در دسترس

بیلدهای ایستای musl برای x86_64 و arm64: سیدباکس‌ها، VPSها، هر NAS با SSH، Raspberry Pi 4/5. بدون رولت نسخهٔ glibc.

x86_64 · arm64 · واحد systemd گنجانده شده

x86_64 arm64

🐳 Docker در دسترس

ایمیج چندمعماری (amd64 + arm64) روی Docker Hub و ghcr، اینترپوینت PUID/PGID به سبک linuxserver، healthcheck، فایل compose. مسیر Unraid، TrueNAS SCALE و QNAP Container Station هم همین است.

docker run -d -p 6789:6789 \
  -v ./config:/config -v ./downloads:/downloads -v ./watch:/watch \
  nzbfast/nzbfast

🧡 Unraid در دسترس

در Community Applications: در زبانهٔ Apps عبارت nzbfast را جست‌وجو کنید و Install را بزنید. قالب پورت 6789، سه مسیر و شناسه‌های کاربری Unraid را پر می‌کند، پس چیزی برای نوشتن دستی نمی‌ماند.

📦 Synology در دسترس

روی DSM 7 از طریق Container Manager اجرا می‌شود: در Registry عبارت nzbfast را جست‌وجو کنید، دانلود کنید، سه پوشه و پورت 6789 را نگاشت کنید. هیچ فایل پیکربندی‌ای برای ویرایش نیست: ارائه‌دهنده‌تان را از پنل خوش‌آمدگویی داشبورد اضافه کنید.

فایل compose، با به‌روزرسانی خودکار

🍺 Homebrew در دسترس

یک فرمان روی macOS و Linux، همراه با یک بلوک سرویس تا هنگام ورود اجرا شود (brew services start nzbfast). ارتقا با brew upgrade nzbfast انجام می‌شود و تنظیمات و صف شما بیرون از محل نصب می‌مانند، پس از ارتقا جان به در می‌برند.

macOS (Apple Silicon + Intel) · Linux x86_64 + arm64

brew install nzbfast/tap/nzbfast

این دکمه‌ها به نسخهٔ فعلی اشاره می‌کنند. اگر پیوندی از کار افتاد، یا نسخهٔ قدیمی‌تر، جمع‌های کنترلی یا یادداشت‌های انتشار را می‌خواهید، همه در صفحهٔ انتشارهای GitHub موجود است.

تأیید دانلودها: هر انتشار جمع‌های sha256 را کنار مصنوعات در صفحهٔ انتشارها عرضه می‌کند. زیپ‌های macOS بیت‌های اجرایی را حفظ می‌کنند؛ نسخه‌ها هنوز امضا نشده‌اند، بنابراین macOS پیش از اولین اجرا می‌پرسد: روی برنامه راست‌کلیک کنید و «باز کردن» را انتخاب کنید (macOS 14 و پیش‌تر)؛ یا آن را از System Settings → Privacy & Security → Open Anyway (macOS 15 و پس از آن) مجاز کنید.

دو دقیقه تا اولین دانلود

  • 1. اکسترکت کنید و Start nzbfast را اجرا کنید (مک: ‎.command، ویندوز: ‎.bat)، یا فقط ./nzbfast setup در یک ترمینال.
  • 2. جادوگر یک پیکربندی موجود SABnzbd/NZBGet را پیدا می‌کند و پیشنهاد استفاده از آن را می‌دهد؛ در غیر این صورت میزبان، نام کاربری، رمز عبور و تعداد اتصال ارائه‌دهندهٔ شما را می‌پرسد.
  • 3. داشبورد در http://localhost:6789 باز می‌شود. یک ‎.nzb را هرجای آن رها کنید، یا Sonarr/Radarr را به‌عنوان یک کلاینت SABnzbd به آن نشانه بگیرید.

ارتقا یعنی جایگزینی یک فایل. تنظیمات، صف و تاریخچه کنار پیکربندی شما زندگی می‌کنند و از راه‌اندازی مجدد و ارتقاها جان به در می‌برند.

یادداشت‌های پلتفرم

  • Raspberry Pi / ARM NAS: از بیلد Linux arm64 استفاده کنید. رمزگشایی SIMD موتور هسته‌های NEON دارد؛ یک Pi 5 گیگابیت را با فضای مانور اشباع می‌کند.
  • Unraid: در Community Apps: در زبانهٔ Apps عبارت nzbfast را جست‌وجو کنید و نصب کنید (تصویر Docker در زیر). راهنمای گام‌به‌گام →
  • TrueNAS SCALE: تصویر Docker را به‌عنوان یک اپ سفارشی اجرا کنید.
  • FreeBSD / سایر: cargo build --release از منبع انتظار می‌رود کار کند (rustls، بدون OpenSSL)؛ رسماً آزموده نشده. تعمیر PAR2 و باز کردن RAR روی هر پلتفرم بومی‌اند.
  • گوشی‌ها: چیزی برای نصب نیست: داشبورد یک چیدمان گوشی درجه‌یک دارد، و nzb360/LunaSea از طریق API سازگار با NZBGet متصل می‌شوند.
