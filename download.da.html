Én binær. Alt følger med.

Hvert build er én selvstændig eksekverbar fil: reparation (par2) og udpakning (RAR) er indlejret. Pak ud, kør starteren, svar på tre spørgsmål, hent.

🍎 macOS tilgængelig

NzbFast-appen: træk til Programmer og i gang. Universal (Apple Silicon og Intel), dashboard i sit eget vindue, dobbeltklik på .nzb, start ved login.

macOS 12+ · ~16 MB DMG · app + motor

Endnu ikke notariseret af Apple, så første start kræver to ekstra klik; DMG’en guider dig igennem, og en komplet vejledning ligger på selve disken.

Download Mac-appen bærbar .zip

🪟 Windows tilgængelig

Installeren sætter en tray-app op (intet konsolvindue), en post i Start-menuen, valgfri start-med-Windows og dobbeltklik på .nzb. Fuldt statisk, ingen runtime at installere; den kan også overtage din eksisterende SABnzbd-konfiguration.

Windows 10/11 x64 · ~8 MB installer

Download installeren bærbar .zip

🐧 Linux tilgængelig

Statiske musl-builds til x86_64 og arm64: seedboxe, VPS'er, enhver NAS med SSH, Raspberry Pi 4/5. Ingen glibc-versions-roulette.

x86_64 · arm64 · systemd-unit inkluderet

🐳 Docker tilgængelig

Multi-arch-image (amd64 + arm64) på Docker Hub og ghcr, PUID/PGID-entrypoint i linuxserver-stil, healthcheck, compose-fil. Også vejen for Unraid, TrueNAS SCALE og QNAP Container Station.

docker run -d -p 6789:6789 \
  -v ./config:/config -v ./downloads:/downloads -v ./watch:/watch \
  nzbfast/nzbfast

🍺 Homebrew tilgængelig

Én kommando på macOS og Linux, med en service-blok så den starter ved login (brew services start nzbfast). Opgradering er brew upgrade nzbfast, og dine indstillinger og din kø ligger uden for installationen, så de overlever den.

macOS (Apple Silicon + Intel) · Linux x86_64 + arm64

brew install nzbfast/tap/nzbfast

Knapperne peger på den aktuelle version. Hvis et link holder op med at virke, eller du vil have en ældre version, kontrolsummerne eller udgivelsesnoterne, ligger det hele på GitHubs releaseside.

Verificering af downloads: hver udgivelse leveres med sha256-summer ved siden af artefakterne på udgivelsessiden. macOS-zips bevarer eksekveringsbits; udgivelserne er endnu ikke signerede, så macOS spørger før første start: højreklik på appen og vælg Åbn (macOS 14 og tidligere), eller tillad den under Systemindstillinger → Anonymitet & sikkerhed → Åbn alligevel (macOS 15 og nyere).

To minutter til første download

  • 1. Pak ud og kør Start nzbfast (mac: .command, windows: .bat), eller bare ./nzbfast setup i en terminal.
  • 2. Guiden finder en eksisterende SABnzbd-/NZBGet-konfiguration og tilbyder at bruge den; ellers spørger den om din udbyders host, brugernavn, adgangskode og antal forbindelser.
  • 3. Dashboardet åbner på http://localhost:6789. Smid en .nzb hvor som helst på det, eller ret Sonarr/Radarr mod det som en SABnzbd-klient.

At opgradere er at udskifte én fil. Indstillinger, kø og historik ligger ved siden af din konfiguration og overlever genstarter og opgraderinger.

Platformsnoter

  • Raspberry Pi / ARM-NAS: brug Linux arm64-buildet. Motorens SIMD-afkodning har NEON-kerner; en Pi 5 mætter gigabit med reserve.
  • Unraid: i Community Apps: søg efter nzbfast i Apps-fanen og installér (Docker-image nedenunder). Trin-for-trin-guide →
  • TrueNAS SCALE: kør Docker-imaget som en custom app.
  • FreeBSD / andre: cargo build --release fra kildekode forventes at virke (rustls, ingen OpenSSL); officielt utestet. PAR2-reparation og RAR-udpakning er native på alle platforme.
  • Telefoner: intet at installere: dashboardet har et førsteklasses telefonlayout, og nzb360/LunaSea forbinder via det NZBGet-kompatible API.
