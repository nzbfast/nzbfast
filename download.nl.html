Eén binary. Alles inbegrepen.

Elke build is één op zichzelf staand uitvoerbaar bestand: herstel (par2) en uitpakken (RAR) zitten erin. Uitpakken, launcher starten, drie vragen beantwoorden, downloaden.

🍎 macOS beschikbaar

De NzbFast-app: sleep naar Programma's en klaar. Universal (Apple Silicon en Intel), dashboard in een eigen venster, .nzb-dubbelklik, starten bij inloggen.

macOS 12+ · ~16 MB DMG · app + engine

Nog niet door Apple genotariseerd, dus de eerste start kost twee extra klikken; de DMG loodst je erdoorheen, met een volledige handleiding op de schijf zelf.

Download de Mac-app draagbare .zip

🪟 Windows beschikbaar

De installer zet een tray-app op (geen consolevenster), een vermelding in het Startmenu, optioneel starten met Windows en .nzb-dubbelklik. Volledig statisch, geen runtime te installeren; hij kan ook je bestaande SABnzbd-config overnemen.

Windows 10/11 x64 · ~8 MB installer

🐳 Docker beschikbaar

Multi-arch image (amd64 + arm64) op Docker Hub en ghcr, PUID/PGID-entrypoint in linuxserver-stijl, healthcheck, compose-bestand. Ook de route voor Unraid, TrueNAS SCALE en QNAP Container Station.

docker run -d -p 6789:6789 -e NZBFAST_OUT=/data/usenet \
  -v /srv/nzbfast/config:/config -v /srv/nzbfast/watch:/watch \
  -v /data/usenet:/data/usenet nzbfast/nzbfast

🍺 Homebrew beschikbaar

Eén commando op macOS en Linux, met een serviceblok zodat het start bij inloggen (brew services start nzbfast). Upgraden is brew upgrade nzbfast, en je instellingen en wachtrij staan buiten de installatie, dus ze overleven het.

macOS (Apple Silicon + Intel) · Linux x86_64 + arm64

brew install nzbfast/tap/nzbfast

Deze knoppen verwijzen naar de huidige versie. Werkt een link niet meer, of wil je een oudere build, de checksums of de release-notities, dan staat alles op de GitHub-releasespagina.

Downloads verifiëren: elke release levert sha256-sommen naast de artifacts op de releasespagina. macOS-zips behouden de executable-bits; de builds zijn nog niet ondertekend, dus macOS vraagt om bevestiging bij de eerste start: rechtsklik op de app en kies Open (macOS 14 en ouder), of sta hem toe via Systeeminstellingen → Privacy en beveiliging → Open toch (macOS 15 en nieuwer).

Twee minuten tot je eerste download

  • 1. Pak uit en start Start nzbfast (mac: .command, windows: .bat), of gewoon ./nzbfast setup in een terminal.
  • 2. De wizard vindt een bestaande SABnzbd/NZBGet-config en biedt aan die te gebruiken; anders vraagt hij om de host, gebruikersnaam, wachtwoord en het aantal verbindingen van je provider.
  • 3. Het dashboard opent op http://localhost:6789. Zet er een .nzb op (waar dan ook) of richt Sonarr/Radarr erop als SABnzbd-client.

Upgraden is één bestand vervangen. Instellingen, wachtrij en geschiedenis staan naast je config en overleven herstarts en upgrades.

Platformnotities

  • Raspberry Pi / ARM-NAS: gebruik de Linux arm64-build. De SIMD-decode van de engine heeft NEON-kernels; een Pi 5 verzadigt gigabit met marge over.
  • Unraid: in Community Apps: zoek nzbfast op het tabblad Apps en installeer (Docker-image eronder). Stapsgewijze handleiding →
  • TrueNAS SCALE: draai de Docker-image als custom app.
  • FreeBSD / overige: cargo build --release vanaf de broncode werkt naar verwachting (rustls, geen OpenSSL); officieel niet getest. PAR2-herstel en RAR-uitpakken zijn native op alle platforms.
  • Telefoons: niets te installeren: het dashboard heeft een volwaardige telefoonweergave, en nzb360/LunaSea verbinden via de NZBGet-compatibele API.
