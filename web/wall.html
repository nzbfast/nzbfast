This nzbfast asks for its API key

Find it on the machine running nzbfast: Settings > Security > API key (Show), or in the daemon's startup log. Once it checks out it is remembered in this browser only.

If the key was just changed, the browser where that happened shows the new one. If no browser does, look in nzbfast's settings folder: it is on the apikey line of settings.json, or in a file called apikey beside it.
