Eine Binary. Alles inklusive.

Jeder Build ist eine einzige, in sich geschlossene Programmdatei: Reparatur (par2) und Entpacken (RAR) sind eingebettet. Auspacken, Launcher starten, drei Fragen beantworten, herunterladen.

🍎 macOS verfügbar

Die NzbFast-App: in „Programme“ ziehen und loslegen. Universal (Apple Silicon und Intel), Dashboard im eigenen Fenster, .nzb per Doppelklick, Start bei Anmeldung.

macOS 12+ · ~16 MB DMG · App + Engine

Noch nicht von Apple notarisiert, der erste Start kostet also zwei zusätzliche Klicks; das DMG führt dich hindurch, und eine vollständige Anleitung liegt direkt auf dem Volume.

Mac-App laden portable .zip

🪟 Windows verfügbar

Der Installer richtet eine Tray-App ein (kein Konsolenfenster), einen Startmenü-Eintrag, optional Autostart mit Windows und .nzb per Doppelklick. Voll statisch, keine Runtime zu installieren; er kann auch deine bestehende SABnzbd-Konfiguration übernehmen.

🐧 Linux verfügbar

Statische musl-Builds für x86_64 und arm64: Seedboxen, VPS, jedes NAS mit SSH, Raspberry Pi 4/5. Kein glibc-Versions-Roulette.

x86_64 · arm64 · systemd-Unit dabei

🐳 Docker verfügbar

Multi-Arch-Image (amd64 + arm64) auf Docker Hub und ghcr, PUID/PGID-Entrypoint im linuxserver-Stil, Healthcheck, Compose-Datei. Auch der Weg für Unraid, TrueNAS SCALE und QNAP Container Station.

docker run -d -p 6789:6789 \
  -v ./config:/config -v ./downloads:/downloads -v ./watch:/watch \
  nzbfast/nzbfast

🧡 Unraid verfügbar

In Community Applications: suche nzbfast im Apps-Tab und klick auf Install. Die Vorlage füllt Port 6789, die drei Pfade und die Unraid-Benutzer-IDs aus, es bleibt nichts von Hand zu schreiben.

🍺 Homebrew verfügbar

Ein Befehl auf macOS und Linux, mit einem Service-Block, damit es bei der Anmeldung startet (brew services start nzbfast). Ein Upgrade ist brew upgrade nzbfast, und deine Einstellungen und die Warteschlange liegen außerhalb der Installation, überstehen es also.

macOS (Apple Silicon + Intel) · Linux x86_64 + arm64

brew install nzbfast/tap/nzbfast

Diese Schaltflächen verweisen auf die aktuelle Version. Falls ein Link einmal nicht funktioniert oder Sie eine ältere Version, die Prüfsummen oder die Versionshinweise suchen: Alles finden Sie auf der GitHub-Releases-Seite.

Downloads verifizieren: jedes Release liefert sha256-Summen neben den Artefakten auf der Releases-Seite. macOS-Zips bewahren die Executable-Bits; die Builds sind noch nicht signiert, daher fragt macOS vor dem ersten Start nach: Rechtsklick auf die App und „Öffnen" wählen (macOS 14 und älter), oder erlaube sie unter Systemeinstellungen → Datenschutz & Sicherheit → Dennoch öffnen (macOS 15 und neuer).

Zwei Minuten bis zum ersten Download

  • 1. Auspacken und Start nzbfast ausführen (Mac: .command, Windows: .bat), oder einfach ./nzbfast setup im Terminal.
  • 2. Der Assistent findet eine bestehende SABnzbd-/NZBGet-Konfiguration und bietet an, sie zu nutzen; sonst fragt er nach Host, Benutzername, Passwort und Verbindungszahl deines Providers.
  • 3. Das Dashboard öffnet sich unter http://localhost:6789. Zieh eine .nzb irgendwohin darauf, oder richte Sonarr/Radarr als SABnzbd-Client darauf.

Ein Upgrade heißt: eine Datei ersetzen. Einstellungen, Warteschlange und Verlauf liegen neben deiner Konfiguration und überstehen Neustarts und Upgrades.

Plattform-Hinweise

  • Raspberry Pi / ARM-NAS: nimm den Linux-arm64-Build. Die SIMD-Dekodierung der Engine hat NEON-Kernel; ein Pi 5 sättigt Gigabit mit Reserve.
  • Unraid: in den Community Apps: suche nzbfast im Apps-Tab und installiere (Docker-Image darunter). Schritt-für-Schritt-Anleitung →
  • TrueNAS SCALE: führe das Docker-Image als Custom-App aus.
  • FreeBSD / andere: cargo build --release aus dem Quellcode sollte funktionieren (rustls, kein OpenSSL); offiziell ungetestet. PAR2-Reparatur und RAR-Entpacken sind auf allen Plattformen nativ.
  • Handys: nichts zu installieren: Das Dashboard hat ein vollwertiges Handy-Layout, und nzb360/LunaSea verbinden sich über die NZBGet-kompatible API.
