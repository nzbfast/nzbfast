Un singur binar. Cu tot ce trebuie inclus.

Fiecare build este un singur executabil de sine stătător: repararea (par2) și dezarhivarea (RAR) sunt integrate. Dezarhivezi, rulezi launcherul, răspunzi la trei întrebări, descarci.

🍎 macOS disponibil

Aplicația NzbFast: trage în Applications și gata. Universală (Apple Silicon și Intel), panou în propria fereastră, dublu-clic pe .nzb, pornire la autentificare.

macOS 12+ · DMG ~16 MB · aplicație + motor

Încă nenotarizată de Apple, așa că prima lansare cere două clicuri în plus; DMG-ul te ghidează, iar un ghid complet se află chiar pe disc.

🪟 Windows disponibil

Installerul configurează o aplicație în tray (fără fereastră de consolă), o intrare în meniul Start, pornire opțională odată cu Windows și dublu-clic pe .nzb. Complet static, fără runtime de instalat; poate adopta și configurația ta SABnzbd existentă.

Windows 10/11 x64 · installer ~8 MB

🐧 Linux disponibil

Build-uri musl statice pentru x86_64 și arm64: seedbox-uri, VPS-uri, orice NAS cu SSH, Raspberry Pi 4/5. Fără ruletă de versiuni glibc.

x86_64 · arm64 · unitate systemd inclusă

🐳 Docker disponibil

Imagine multi-arch (amd64 + arm64) pe Docker Hub și ghcr, entrypoint PUID/PGID în stil linuxserver, healthcheck, fișier compose. Este și calea pentru Unraid, TrueNAS SCALE și QNAP Container Station.

docker run -d -p 6789:6789 -e NZBFAST_OUT=/data/usenet \
  -v /srv/nzbfast/config:/config -v /srv/nzbfast/watch:/watch \
  -v /data/usenet:/data/usenet nzbfast/nzbfast

🍺 Homebrew disponibil

O singură comandă pe macOS și Linux, cu un bloc de serviciu ca să pornească la autentificare (brew services start nzbfast). Upgrade-ul se face cu brew upgrade nzbfast, iar setările și coada ta stau în afara instalării, așa că îi supraviețuiesc.

macOS (Apple Silicon + Intel) · Linux x86_64 + arm64

brew install nzbfast/tap/nzbfast

Aceste butoane trimit către versiunea curentă. Dacă un link nu mai funcționează sau doriți o versiune mai veche, sumele de control ori notele de lansare, toate se află pe pagina de lansări GitHub.

Verificarea descărcărilor: fiecare release vine cu sume sha256 lângă artefacte pe pagina de release-uri. Zip-urile macOS păstrează biții de execuție; build-urile nu sunt încă semnate, așa că macOS cere confirmare înainte de prima lansare: clic dreapta pe aplicație și alege Deschide (macOS 14 și anterioare), sau permite-o din System Settings → Privacy & Security → Open Anyway (macOS 15 și ulterioare).

Două minute până la prima descărcare

  • 1. Dezarhivează și rulează Start nzbfast (mac: .command, windows: .bat), sau doar ./nzbfast setup într-un terminal.
  • 2. Asistentul găsește o configurație SABnzbd/NZBGet existentă și se oferă să o folosească; altfel îți cere hostul providerului, numele de utilizator, parola și numărul de conexiuni.
  • 3. Panoul se deschide la http://localhost:6789. Trage un .nzb oriunde pe el, sau îndreaptă Sonarr/Radarr spre el ca client SABnzbd.

Upgrade-ul înseamnă înlocuirea unui singur fișier. Setările, coada și istoricul se află lângă configurația ta și supraviețuiesc repornirilor și upgrade-urilor.

Note despre platforme

  • Raspberry Pi / NAS ARM: folosește build-ul Linux arm64. Decodarea SIMD a motorului are kernele NEON; un Pi 5 saturează gigabitul cu marjă.
  • Unraid: în Community Apps: caută nzbfast în fila Apps și instalează (cu imaginea Docker dedesubt). Ghid pas cu pas →
  • TrueNAS SCALE: rulează imaginea Docker ca aplicație personalizată.
  • FreeBSD / altele: cargo build --release din sursă ar trebui să funcționeze (rustls, fără OpenSSL); netestat oficial. Repararea PAR2 și dezarhivarea RAR sunt native pe toate platformele.
  • Telefoane: nimic de instalat: panoul are un aspect de telefon de primă clasă, iar nzb360/LunaSea se conectează prin API-ul compatibil NZBGet.
