Un binario. Todo incluido.

Cada compilación es un único ejecutable autocontenido: la reparación (par2) y el desempaquetado (RAR) van integrados. Descomprime, ejecuta el lanzador, responde tres preguntas y descarga.

🍎 macOS disponible

La app NzbFast: arrástrala a Aplicaciones y listo. Universal (Apple Silicon e Intel), panel en su propia ventana, doble clic en .nzb, inicio al iniciar sesión.

macOS 12+ · DMG de ~16 MB · app + motor

Aún sin notarizar por Apple, así que el primer arranque exige dos clics más; el DMG te acompaña, con una guía completa en el propio disco.

Descargar la app de Mac .zip portátil

🪟 Windows disponible

El instalador configura una app en la bandeja (sin ventana de consola), una entrada en el menú Inicio, arranque con Windows opcional y doble clic en .nzb. Totalmente estático, sin runtime que instalar; también puede adoptar tu configuración existente de SABnzbd.

Windows 10/11 x64 · instalador de ~8 MB

Descargar el instalador .zip portátil

🐧 Linux disponible

Compilaciones estáticas con musl para x86_64 y arm64: seedboxes, VPS, cualquier NAS con SSH, Raspberry Pi 4/5. Sin ruleta de versiones de glibc.

x86_64 · arm64 · unidad systemd incluida

x86_64 arm64

🐳 Docker disponible

Imagen multiarch (amd64 + arm64) en Docker Hub y ghcr, entrypoint PUID/PGID al estilo linuxserver, healthcheck, archivo compose. También es la vía para Unraid, TrueNAS SCALE y QNAP Container Station.

docker run -d -p 6789:6789 \
  -v ./config:/config -v ./downloads:/downloads -v ./watch:/watch \
  nzbfast/nzbfast

🧡 Unraid disponible

En Community Applications: busca nzbfast en la pestaña Apps y pulsa Install. La plantilla rellena el puerto 6789, las tres rutas y los IDs de usuario de Unraid: no hay nada que escribir a mano.

🍺 Homebrew disponible

Un solo comando en macOS y Linux, con un bloque de servicio para que arranque al iniciar sesión (brew services start nzbfast). Para actualizar, brew upgrade nzbfast, y tus ajustes y tu cola viven fuera de la instalación, así que sobreviven a la actualización.

macOS (Apple Silicon + Intel) · Linux x86_64 + arm64

brew install nzbfast/tap/nzbfast

Estos botones apuntan a la versión actual. Si algún enlace deja de funcionar, o quieres una versión anterior, las sumas de verificación o las notas de la versión, está todo en la página de releases de GitHub.

Verificar las descargas: cada versión incluye sumas sha256 junto a los artefactos en la página de versiones. Los zip de macOS conservan los bits de ejecución; las versiones aún no están firmadas, así que macOS pregunta antes del primer arranque: haz clic derecho en la app y elige Abrir (macOS 14 y anteriores), o permítela en Ajustes del Sistema → Privacidad y seguridad → Abrir igualmente (macOS 15 y posteriores).

Dos minutos hasta la primera descarga

  • 1. Descomprime y ejecuta Start nzbfast (mac: .command, windows: .bat), o simplemente ./nzbfast setup en un terminal.
  • 2. El asistente encuentra una configuración existente de SABnzbd/NZBGet y se ofrece a usarla; si no, te pide el host, el usuario, la contraseña y el número de conexiones de tu proveedor.
  • 3. El panel se abre en http://localhost:6789. Suelta un .nzb en cualquier parte, o apunta Sonarr/Radarr hacia él como cliente SABnzbd.

Actualizar es reemplazar un archivo. Los ajustes, la cola y el historial viven junto a tu configuración y sobreviven a reinicios y actualizaciones.

Notas por plataforma

  • Raspberry Pi / NAS ARM: usa la compilación Linux arm64. La decodificación SIMD del motor tiene kernels NEON; una Pi 5 satura el gigabit con margen de sobra.
  • Unraid: en Community Apps: busca nzbfast en la pestaña Apps e instala (imagen Docker por debajo). Guía paso a paso →
  • TrueNAS SCALE: ejecuta la imagen Docker como una app personalizada.
  • FreeBSD / otros: se espera que cargo build --release desde el código funcione (rustls, sin OpenSSL); oficialmente sin probar. La reparación PAR2 y la extracción RAR son nativas en todas las plataformas.
  • Teléfonos: nada que instalar: el panel tiene un diseño para móvil de primera clase, y nzb360/LunaSea se conectan mediante la API compatible con NZBGet.
